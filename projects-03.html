Notes — a markdown journal

A minimal, local-first journaling app for writing in markdown without leaving the keyboard.

TypeScriptIndexedDBService Worker

What it does

Stores every entry locally in the browser, so it works fully offline and never phones home.

Notable details

Renders markdown live in a split-pane view as you type.

Installable as a PWA, so it opens like a native app from the home screen.

Exports the whole journal to a single portable markdown file at any time.
