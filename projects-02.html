Task Flow API

A REST API for small-team task management, designed to be boring in the best way: predictable, documented, fast.

Node.jsExpressPostgreSQLVercel

What it does

Provides authenticated endpoints for creating, assigning, and tracking tasks across a team.

Notable details

Deployed as serverless functions, so it scales to zero when idle and costs nothing at rest.

Includes full OpenAPI documentation generated directly from the route definitions.

Covered by an integration test suite that runs on every pull request.
